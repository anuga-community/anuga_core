\chapter*{How to read this report}
\addcontentsline{toc}{chapter}{How to read this report}
%======================
This report runs every validation case with each of the flow algorithms
\algnames{}. The text of each case appears once. A figure that differs
between the algorithms is shown as a row of panels, one per algorithm,
labelled above each panel and in the order \algnames{}. In
Chapter~\ref{ch:ea}, where the figures are as wide as the page, the panels
are one above the other instead. A figure that is the
same for all of them (a setup diagram, a mesh) is shown once. Where a case's
text names a single algorithm, it describes that case's own discussion, not
the panels. The separate report for each algorithm, with full-size figures,
is published alongside this one.

The table gives each case's run time for each algorithm, or \textbf{failed}
where the case did not produce its results.
